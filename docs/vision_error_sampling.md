# 固定物块误差采样

本轮先完成实测工具。页面读取现有 V7 原始上视距离和角度，不修改主控、视觉、追球或底层运动参数；无需重新烧录。原来的圆形关联暂时保留，新的关联和卡尔曼参数要在实测后确定。

## 怎么采

1. 刷新桌面 `静止视觉XY联调.html`，连接 UART5 遥测串口，按 KEY4，确认任务回到“等待启动”。点击顶部“误差采样”。采样期间网页 KEY1–3 和点选行驶被暂时阻止；KEY4 仍可使用。页面不向主控发送采样命令，硬件按键功能不变。
2. 车和摄像头保持固定，镜头不能重新掰动。视野中所选颜色只放一个物块，其他同色物块移出视野。不要使用场地图的编号来选采样对象，当前编号本身正在排查。
3. 用尺子测 **视觉标定约定原点到被检测接地点** 的地面 X/Y。X 向右，Y 向前，单位 cm。当前视觉代码以可见贴地边缘计算位置，通常应量到朝摄像头的底边中心，不能随意换成物块中心或保险杠起点。配置只写了 `vehicle_user_defined`，没有说明实物原点具体在哪，因此必须由实际标定者确认并在“原点与测量点说明”里记录。不同约定的数据不要混用。
4. 先做绿色正前方：X=0，Y 依次为 30、50、80、120、180、240 cm，每组 20 秒。看不见的距离仍可采一组记录缺失，然后换到能看见的位置，不要用估计值填写真实坐标。每次点“开始本组”，先有 1 秒稳定时间，之后计满设定时长自动结束。
5. 在能识别的近、中、远三个距离再测试左右偏角。例如 `(X,Y)=(±20,50)、(±40,100)、(±60,150)`；这里实际径向距离为 `sqrt(X²+Y²)`，不等于 Y。具体位置以量尺为准，不必凑这些示例数值。
6. 各位置独立重新摆放并复测 2–3 组。橙色、黑色分开采，至少覆盖近/中/远与左右视野。首次可先导出绿色正前方 6 组，用它检查单位、方向和距离偏差，再继续完整采样。
7. 点击“导出采样 JSON”，交回该文件用于分析。CSV 是原始样本便于画图，但原点说明、跳过计数、组状态等完整信息在 JSON 中。页面自动保存当前浏览器缓存，断连和演示不会删除；缓存不是正式备份。删除最后一组会同时更新缓存。

## 采样规则

- 只接收实时串口数据，演示模式不能采样。每个上视新帧至多一条样本；相同帧重传不算多次测量。正常 uint32 回绕可继续，主控时间或视觉帧号回退则结束该组。
- 同色必须唯一，再检查距离/角度是否存在；不以“哪个更靠近填写的真实值”筛选，避免把误差人为筛小。允许 `valid=0` 的估计测距，保留原始标志。
- 上视过期（主控年龄加本行实测组包耗时 >400 ms）、无坐标、未识别、多目标分别计数，不填成 0。重复帧计数是重复收到的遥测包数，其他拒绝计数按接收到的新帧计算。串口中未收到的相机帧无法统计。
- 直接保存原始 `d_mm` 与 `angle`，不从取整后的显示 XY 或融合后的地图位置反推。不会增加遥测字段、报文长度或发送频率。
- 断连、切换数据流、任务启动会结束当前组并保留已有样本。页面关闭前尽量保存；如果采集中刷新，恢复为“本组未完成”，不继续混采。每 2 秒保存一次进度，异常关闭仍可能丢最后一小段，完成后应导出。
- 位姿变化超过 1 cm 或 2° 时只在统计结果中提示检查是否移动，不剔除样本，不改变任何运动限制。这个检查来自当前里程计，只能作提示，不能证明实车完全静止。

## 怎么看统计

真实距离 `r = hypot(X,Y)`；真实方位 `theta = atan2(X,Y)`，右正左负。每条样本：

```
距离误差 = d_mm / 10 - r
角度误差 = wrap_to_180(测得角度 - theta)
平均偏差 = 误差平均值
标准差 σ = sqrt(sum((误差 - 平均偏差)^2) / (N - 1))
```

页面表格显示平均偏差和样本标准差，图里点是每组平均偏差，线段是 ±1σ。没有足够样本时 σ 留空。JSON 还包括 RMSE、绝对误差 P95、径向与方位误差的样本协方差（单位 cm/rad），以及每个原始帧、时间和来源信息。

平均偏差大说明存在固定误差；σ 大说明抖动大。比如一直测成 60 cm、实际 50 cm，偏差是 +10 cm，即使 σ=0 也不准确。不同距离、偏角、颜色和独立重摆组要分别比较，不能把全部数据先混成一个均值。

多帧可能有强相关性；同一组的 σ 不能直接当作最终 EKF 的全部 R。还要检查不同组的偏差、相机/地面标定、车体原点与时间对齐，以及里程计/IMU 不确定性。正前方采样不能验证两侧角度误差，静止采样也不能验证运动时延。

## 实测后的实现

可以采用 **二维静态 EKF**。每个物块保留 `X,Y` 和 2×2 协方差；观测为距离和角度，测量函数包含 `hypot` 和 `atan2`，故用扩展卡尔曼滤波。按实测距离/偏角/颜色估算误差，先分离明显的固定偏差，再设测量噪声与合理的不确定性下限；不把相关的远距离连续帧当成无限多份独立高精度证据。

关联依据预测位置与观测的联合不确定性，做同色整帧一对一分配，并允许“不匹配/待确认”。场地 2 绿、3 橙、1 黑作为可配置数量先验，不强行塞满，也不把不匹配的远点立即变成长期编号。确认地图记录依旧不因 400 ms 过期删除。

当前只交付采样统计；尚无真实采样数据，未生成实测误差模型、未启用新关联或 EKF。需要实际量尺数据后才能完成这一阶段。
