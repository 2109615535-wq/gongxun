# 场地定位与物块长期记忆（2026-11-16）

本版仅增加独立建图、整场物块记录、最近 8 次原始观测历史与页面显示。不做出库扫描、权重选目标或地图驱动的夹持/送回；追球、视觉收发、IMU/编码器、底层运动参数及点选控制算法不改。

## 上板测试

1. 烧录 `outputs/field_memory_20261116/物块长期记忆_独立建图.hex`。刷新桌面 `静止视觉XY联调.html`，连接 UART5 遥测串口（115200、8N1）；香橙派继续使用 USART6（PC6 TX、PC7 RX）和原 RV2 协议。
2. 轮系中心放在场地 (285,80) cm，朝图片上方再上电/复位。起点是之前圈选的估计位置，左下角 (0,0)，X 向右，Y 向上；第一帧 IMU 定为 0°，顺时针为正。`field_map.h` 可改起点及视觉安装偏移。
3. 先不启动任务，车轮贴地手推，观察静止物块的场地位置。原网页点选行驶和 KEY1–4 仍在，手推测试不要点击场地或按 KEY1。查看历史用页面底部的物块下拉框。
4. 让物块离开视野超过 2 秒、出现空帧、断开视觉或电脑串口：地图应保留固定编号和最后接受的位置，点变成历史样式。重新看见附近同类物块时应关联旧编号。
5. 页面底部“物块地图 · 历史位置”选择编号，查看最近 8 次已处理的新帧坐标。地图上的匹配圆和选中物块历史轨迹可开关；这些控件不发运动指令。
6. 重连页面后会自动请求分批同步；“重新同步地图”只读主控记录，不清地图，不启动电机。可导出物块地图 JSON，也可用顶部导出完整接收记录。48 条完整同步至少约 14.4 秒，实际取决于串口占用；常见少量物块更快，页面显示已同步数量。
7. 主控复位或重新初始化场地会清空 RAM 地图并重新编号，页面随地图批次/主控时间回退清除旧记录。刷新页面、短时丢帧、IMU 暂时失效和串口断开都不清主控地图。

## 主控数据与处理

- `field_map_process()` 每 5 ms 独立调度，只读取 `vision.upper` 和已经保存的位姿，不写电机/舵机，不调用遥测。发送队列忙或电脑不接串口都能建图。
- 编码器位移 + IMU 朝向、64 个位姿样本及时间插值沿用原实现。观测时间 = updated_ms - age_ms；不重复加串口耗时。没有可插值的历史时等待，不用当前车位代替。RV2 年龄不包含曝光和相机内部缓存，场地坐标仍是估计。
- 每个已处理的新上视帧只关联一次，重复轮询不刷新时间或增加观测次数；空帧也独立处理。400 ms 仍新鲜，401 ms 过期；过期只隐藏实时观测，不释放历史编号。
- `field_tracks[48]` 是主控整场记录表。保存固定编号、类别、最新观测时间、最新接受位置及其时间、总观测次数、可见状态、待确认状态、版本号，以及 8 个按时间排列的原始坐标样本。使用静态 RAM，无动态分配。满时保留所有旧记录，并累计未入表观测次数，页面提示容量已满。
- 同类别一对一全局最近配对。匹配圆 r = 4 + 0.05 × 距离(cm)，配对距离取新旧观测较大者。超出匹配圆的观测新建编号，不猜测它一定是某个被撞走的物块。没有观测到旧点不等于确认被对方取走。
- 圈内位移超过匹配半径一半时，保留当前地图位置、将新位置作为待确认；连续 3 个已处理新帧都在候选位置附近才接受最后一次原始坐标。中途缺失/过期会重置连续计数。小位移直接采用原始坐标，所有样本都记录，未做平均或平滑。
- 历史样本 `accepted=0` 表示跳变待确认，`accepted=1` 表示当时已接受；后续确认不会修改过去样本的标记。地图位置可能比最近一次看到物块的时间更旧，因此分别保存 position_ms 和 seen_ms。
- 本轮不接入“已夹持/已送达”更新：追球每帧选最近物块的逻辑保持原样。以后接全局目标选择时再关联夹持编号。

## 页面与遥测

现有 V7 实时遥测字段不变。新增独立 M1 行，每行只发一个物块和它的 8 条短历史，单行缓冲 640 字节，最多每 300 ms 一行，与 V7 交替使用空闲发送队列。继续使用 CRC16、64 字节分段、5 ms 间隔；不堆积整张地图的长包。

M1 帧（CRC 覆盖星号前的 ASCII JSON）：

```
["M1",tick,epoch,map_revision,count,unmapped_count,record_or_null]*CRC16
record = [id,kind,x_mm,y_mm,radius_mm,seen_ms,position_ms,
          observations,visible,review,revision,history]
history = [[observation_tick,x_mm,y_mm,accepted], ...最多8条]
```

优先发送变化记录；每 4 个地图包安排一次独立轮询补发，避免频繁变化的一个物块饿死其他记录。页面首次收到 M1 自动发送只读 `MAP\n` 请求全表轮询，按钮可再次请求。无线丢失的记录可由补发或重新同步恢复。

场地图圆点使用主控接受的位置，淡色表示历史；十字表示 V7 当前原始观测。M1 低频分批传输，圆点的记录可能比十字晚更新，尤其物块多时。表格保留采样时间，不把重传时间当作重新看见物块。车体 XY 图仍只用于短时观测，新版长期记录只在场地图显示。旧 V3–V7 固件仍可查看原实时图，但没有 M1 就不显示整场记忆。

历史区域固定高度滚动，目标数量变化不会推挤上面的图。断开串口后保留地图为历史，重新连接会清页面缓存并重新同步主控。主控记录、历史样本和网页缓存都不是已验证的物块真实身份或位置：同类靠近、里程计打滑和视觉标定偏差仍可能误配或产生新编号。
