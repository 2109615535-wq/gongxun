# 普通物块：边走边对准，入区夹持并保持

任务使用 decode_move.c 的 switch(step)，不修改视觉代码或底层驱动。

| case | 行为 |
|---|---|
| 0 | 上电等待；KEY4 停车松开后回到此处 |
| 1 | KEY1 初始化 |
| 10 | 选最近的普通物块，找到后直接进入 30；没有目标就停车等 |
| 30 | 前进同时修正方向；目标丢失停车等待，恢复后自动继续 |
| 40 | 已接受单个普通物块入区事件，停车并立即给 100°，500 ms 后进入完成 |
| 99 | 保持停车和夹持，不因目标消失或视觉异常松开 |

旧 case 20 不再用于原地对准，兼容分支直接转到 30。

## 行驶

前进目标为 50 cm/s。方向修正复用现有 pid.c 的 PID_t、PID_Init()、PID_Update()，不另写一套 PID，也不修改电机 PID 文件或电机参数。

方向参数在 decode_move.c：TASK_STEER_KP=4、TASK_STEER_KI=0、TASK_STEER_KD=2。当前先使用 P+D（积分关闭）抑制来回摆动。目标角设为 0，current=-target_angle，因此正方位角产生正转向指令。原 PID 公式为 Kp*error + Ki*累计error + Kd*(error-上次error)，D 为每个新视觉帧的误差变化，没有另做时间归一化，参数效果与视觉更新频率有关。

仅在新上视帧到达时执行 PID_Update，同一帧多次调度保持该输出；第一帧将历史误差初始化为当前误差，避免重获目标时的微分突跳。原 ±3° 死区保留，进入死区时转向为零并清理历史；丢目标/停车同样清理方向历史。角度从 10° 到 8° 时，新转向输出为 4*8+2*(8-10)=28°/s，相比纯 P 的 32°/s 减弱修正。

不增加实际转向速度上限。为兼容现有 PID API，方向 PID 的 output_max/error_int_max 设为 FLT_MAX（浮点范围），不将它们作为操作速度限制；真正的轮速/PWM 最大值仍仅为用户指定的 90%。保持原 P 项强度，但 D 项会随偏差变化增减输出，已不再是简单“角度×4”。参数为初始上板值，不能仅凭仿真保证消除摆动。

按用户澄清保留前进加速度 30 cm/s²：drive() 按实际毫秒间隔逐步调整前进指令，每 20 ms 增加 0.6 cm/s，从静止到 50 cm/s 约需 1.67 s。这限制速度变化率，不是速度上限；更大的速度给定仍可以继续加速到达。方向 PID 输出直接作为转向指令，不添加角速度上限或角加速度限制。丢目标、入区、KEY4 停车仍立即清零输出和渐变状态，恢复后从零加速。

body_move() 完成四轮逆运动学和现有标定换算后，检查四轮归一化目标的最大绝对值。超过 900 时，四轮同时乘以 900/max_abs，保持轮速比例；未超过则原样发送。MOTOR_WHEEL_LIMIT=900 对应 90%，MOTOR_SPEED_MAX=1000 仍是归一化/PWM 分母，不能改成 900。

现有接口中的轮速目标是归一化编码器速度，并不等同于实时 PWM；速度 PID 的输出和最终 PWM 也限制在 ±900，确保实际占空比最高 90%。直接 MotorSetSpeedN() 超出轮速最大值时截到 ±900；MotorSetPWM() 对四轮请求同比缩放，超过 90% 时才处理。PID 增益、编码器采样、里程计和视觉代码保持原样。实际车速、转向与机械抓取效果仍需上板验证。

每次选当前帧最近的普通物块，允许估计坐标 valid=0，不锁定旧 ID/位置。需要有效数值的正距离和前方角度，以及状态正常、年龄 <=400 ms 的上视观测。丢目标或观测过期先停车，恢复继续，不超时退出。前进时下视也需正常，缺下视则停车等待。危险物、ROI 多物块或非普通物块在未触发夹持前会停车等待。

## 入区与持有记录

新的下视观测中，单个普通物块 in_roi=1 即锁存一次夹持请求。不再要求连续 3 帧，也不要求上视仍能看到物块；已经很靠近、只在下视看得到时也可触发。多个报文在一次循环内到达时，即使后续帧变为 in_roi=0，也保留已经接受的请求。

move() 发现请求即停止驱动，并在同一次调度中执行夹爪 100°。按用户确认的机构行为，发出夹持指令时记录已持有普通物块。没有额外轮速等待或 150 ms 等待；500 ms 只是夹持动作完成状态的等待，不延迟发出闭合指令。

持有记录是 task_info.held_kind，类型编码沿用 VisionKind：VISION_NONE/0 表示空爪，VISION_GREEN/1 表示普通物块。当前任务只夹普通物块，其他类别不会误记为普通物块。

记录一旦建立，in_roi=0、目标遮挡、过期、串口错误或视觉断开都不清除它、不自动松开。已持有时 KEY1 不会开启新任务并误松开。KEY4 是明确的停止和松开操作：夹爪回 50°、记录清为 VISION_NONE、取消待夹持请求并回 case 0。断电后的物理状态不由软件保证，持有记录不写入 Flash。

## 遥测

V3 紧凑报文第 16 项扩展为 [step,reason,inside_count,outside_count,held_kind]，只增加一个数字（通常 2 字节），发送周期和分段保持不变。页面兼容旧 4 项任务字段，旧固件的持有记录显示未知。

新页面显示“已持有：普通物资 · 保持夹持”。持有记录独立于当前视觉目标列表：视觉看不到物块时目标列表可以为空，持有记录仍保留。遥测中断时页面显示当前记录未知，不拿旧数据显示实时状态。

## 验证

回归覆盖：实际 pid.c 的方向 PD、新帧更新、D 项减弱修正、死区及丢失重获复位、30 cm/s² 前进加速度、50 cm/s 前进指令、左右比例转向、±3° 死区、无任务层转向限幅、四轮 90% 同比缩放、不按距离降速、丢失恢复、400/401 ms 观测边界、单帧入区、队列内入区后出区仍夹持、夹持期间和完成后遮挡/错误不松开、持有类别实际序列化、旧网页数据兼容、KEY1 防误松、KEY4 释放及清除记录。实车运动与夹持效果待上板验证。


## 用户指定的限制原则

默认不新增用户未明确指定的速度限制。当前明确保留前进加速度 30 cm/s² 和轮速/PWM 最大 90%；50 cm/s 是任务给定值，不是通用速度上限。方向 PID 输出不另设转向速度上限。
