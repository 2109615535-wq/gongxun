## 版本来源

## 取消加减速限制

`motor.h` 的 `MOTOR_WHEEL_ACCEL_ENABLE` 定义已注释。原四轮统一比例加减速代码保留在 `motor.c` 对应条件编译块中，目前不执行；100 cm/s² 参数也保留但不生效。昨天追球中原有的 30 cm/s² 前进渐变不恢复。

数据流：`body_move(前进cm/s,右移cm/s,顺时针deg/s)` → 四轮逆运动学 → 超过90%时四轮同比缩放 → 当次电机调度直接更新轮速目标 → 原电机速度PID → PWM。加速、减速、反向均不再做渐变。车体速度和转速没有新增上限。

`body_stop()` 设置零目标，下一次电机调度直接应用。追球/点选任务的 `drive_stop()` 恢复昨天的停机方式：立即 `Motor_SetDriveEnabled(0)` 并清除方向 PID 历史。KEY4 立即关闭 PWM、松爪到50°、取消任务。上电不运动。

`MOTOR_WHEEL_LIMIT=900` 与最终90% PWM限制保留，`MOTOR_SPEED_MAX=1000` 仍作归一化分母。轮速给定与实际PWM不同。`Motor_StopTime()`、`body_brake_distance()` 在渐变关闭时返回0，只表示没有软件渐变时间，不代表机械能瞬间静止。

## 同一个追球控制器

`decode_move.c` 中只有一个 `follow_target(angle, frame, distance_cm, speed_cm_s, source)`：

```c
static void follow_target(float angle, uint32_t frame, float distance_cm,
                          float speed_cm_s, uint8_t source)
{
    if (near_align_state == 0 && distance_cm <= 25.0f) near_align_state = 1;
    if (near_align_state == 1) {
        if (fabsf(angle) <= 10.0f) near_align_state = 2;
        else speed_cm_s = 0;
    }
    steer_state.source = source;
    drive(speed_cm_s, steering_pid(angle, frame));
}
```

`near_align_state`：0未检查、1正在原地对准、2本轮已完成。首次进入25cm内，若误差大于10°则只暂停前进，同一个PID继续控制转向；误差小于等于10°后恢复设定前进速度，不再重复对准。首次进入时已经对准也消耗本次检查。短暂丢失和停车等待不重置；KEY1开始新一轮任务、新点选或停止任务会重置。真实追球仍逐帧选择最近普通物块，没有新增物理目标身份锁定。

真实物块：上摄像头每帧选最近普通物块，取它的方位角和帧号，按50cm/s调用。距离/方位允许估计值 valid=0；400ms观测过期、下视缺失、危险物等既有判断保留。丢目标停车等待，恢复继续。

点选：场地坐标减去当前车位，并用当前IMU朝向旋转到车体系；得到右向 `right`、前向 `forward` 后，`angle=atan2(right,forward)`，调用上面的同一函数。只转换目标，不修改视觉报文，不伪造视觉有效标记，不调用夹持逻辑。点选保持已有夹持物。网页速度默认50cm/s，直接传递用户设定值。

```c
dx = target_x - field_map.robot.x;
dy = target_y - field_map.robot.y;
right   = dx*cosf(yaw) - dy*sinf(yaw);
forward = dx*sinf(yaw) + dy*cosf(yaw);
follow_target(atan2f(right, forward)*180.0f/3.1415926f,
              field_map.robot.tick, hypotf(dx, dy), speed_cm_s, 2);
```

点选与追球共用前进叠加转向，25cm内采用上述一次原地对准。旧点选独立PD、D滤波、轮速约束投影、固定行驶朝向和末端提前减速均移除。

方向默认参数只有一处：`TASK_STEER_KP=3.5`、`TASK_STEER_KI=0`、`TASK_STEER_KD=5`，保留±1°死区。追球按新视觉帧更新，点选按新里程计位姿时间戳更新，同一帧不重复积分。原PID没有按dt归一化，D项为 `kd * (error_now - error_last)`，调I/D时应注意两种数据源的实际更新频率；四个电机PID参数不变。

`PID_Init()` 已修复为只清历史状态，保留kp/ki/kd/output_max/error_int_max。因此设置非零I后可以正常累积；当前默认I=0。停车、换目标、KEY1不会丢参数。实时参数位于同一个pid_steer，网页可改，断电恢复宏默认值。

## 任务和到位

| case | 功能 |
|---|---|
| 0 | 上电等待或停止 |
| 1 | KEY1初始化追球 |
| 10 | 找最近普通物块 |
| 30 | 共用follow_target前进并修正方向 |
| 40 | 下视单个普通物块in_roi首次为1，即停车并夹到100° |
| 99 | 记录并保持持有，不因ROI丢失松开 |
| 50 | 网页点选的虚拟目标追踪 |
| 51 | 坐标到位并锁定停车 |

点选仍以车体里程计原点为目标参考，场地X向右、Y向上、单位cm。`task_goto(x,y,speed)` 每20ms从case调用；`task_goto_start()` 切换目的地/重新启动。小于等于2cm锁定停车，之后即使滑出也不再追；不要求最终朝向，不做避障。失去有效位姿就停车等待；无超时失败。

真实追球通过 `in_roi` 结束接近，点选通过2cm距离结束接近。这一完成条件必须不同，方向和前进控制完全共用。恒速追踪侧后方或近距离点可能绕行，取消末端减速后也可能越过停点；当前采用25cm内一次原地对准缓解近距离绕行，没有新增速度上限或末端减速。

## 角度环在线调参（2026-11-16）

打开桌面原有“静止视觉XY联调.html”，连接115200串口，点击顶部“角度环调参”。该页显示PID目标、内部实际值、差值、转向输出和P/I/D分项，并绘制最近20秒曲线。目标相对方位角为angle时，内部current=-angle、target=0，error=angle；这些是对准的相对角，不是IMU场地朝向。

输入P/I/D后点击应用，主控确认并通过遥测回读。参数修改只清理角度PID历史，不启动/停止车辆、不改电机PID；KEY1/KEY4按钮与实体按键一致。支持非负参数，传输保留4位小数，RAM保存，复位恢复默认值。读取按钮读取主控最新参数，不发送运动指令。显示过期/停车时用“—”表示无有效角度输入。

UART5新增CRC短指令 `C1,id,P,Kp乘10000,Ki乘10000,Kd乘10000*CRC`；`C1,id,T,1*CRC` 打开S1，T,0关闭。订阅6秒到期，页面每2秒续订；只在调参页打开时额外发S1，最多5Hz，空闲发送、无排队积压。原V7、地图报文和视觉协议不变。

S1字段为 `["S1",tick,source,age|null,target,current,error,out,P项,I项,D项,kp,ki,kd]*CRC`。source=0无角度输入、1视觉物块、2点选坐标。age是距上次PID计算的时间；页面加实测收包与页面等待，不代表摄像头曝光年龄。

## 当前角度死区：±1°

`TASK_ANGLE_DEAD_DEG=1.0f`。绝对误差小于等于1°时转向指令为0，清除角度积分和差分历史，保留参数和实际误差显示，前进速度不变；大于1°恢复PID。离开死区第一帧不产生D突跳；重复同一帧不重复计算或刷新输入时间。追球和点选共用此规则，在线调参页标注已同步。
