## 2. 扩展协议解析和结构

完整线上格式为：

```text
RV3,source,frame_id,age_ms,status,count[,kind,distance_mm,distance_valid,in_roi,angle,x_mm,y_mm,zone_kind,inside_valid,object_inside ...]*CRC16\n
```

固定头仍为 6 项。每个目标原来的 5 项保持顺序，追加 5 项：

- `x_mm/y_mm`：有符号地面坐标，范围 -65535～65535 mm，X 向右为正、Y 向前为正。未知时两者同时为 `NA`；负数和 0 都是合法坐标。
- `zone_kind`：当前物体入仓核验的实际安全区，四类红蓝物资/伤员区之一，未知为 `NA`。
- `inside_valid`：视觉入仓判断有效位，0 或 1。
- `object_inside`：完整物体 ROI 位于对应安全区内、同一物体和区域连续 3 帧满足后的结果，0 或 1。

保留现有距离、角度和夹爪 ROI 字段：距离未知为 -1；角度未知为 `NA`，单位为度、前方 0、右正左负。角度是目标方位，不是安全区自身朝向。

接收结构及业务结构增加 `x_mm/y_mm/position_present/zone_kind/inside_valid/object_inside`；观测结构可记录 `protocol_version`。`position_present` 仅表示 X/Y 有数值，位置是否有效仍检查 `distance_valid`；`angle_present` 继续区分未知角度与合法 0°。

RV1、RV2、RV3 分别按每目标 4、5、10 个字段解析，不修改旧版布局。每帧最多 12 个目标；RV3 行缓冲上限扩大到 1024 字节，RV1/RV2 保持 512 字节限制，包含 CRC、不含换行。相应扩展字段指针数组或分词器容量。

CRC16-CCITT-FALSE、115200/8N1、现有 USART6 和接收队列均可复用，无需更换串口或增加 JSON 解析器。拒绝 X/Y 只提供一个、入仓标志有效但区域未知、已入仓却判断无效，以及物资/伤员与安全区类别不匹配等报文。

## 3. 保留独立有效位和过期处理

- 距离、角度和直接 X/Y 用于控制时，检查当前相机观测可用、足够新鲜及其位置有效位。数值存在不等于测距已经验证。
- `inside_valid` 独立于 `distance_valid`：入仓判断使用图像 ROI，测距标定尚未验证时，也可能得到有效的视觉入仓判断。
- 累计年龄达到 150 ms 时，清除距离/角度有效位，并清除 `inside_valid` 和 `object_inside`。重复图像不能延长有效期，RV1/RV2 报文不能保留上一次 RV3 的入仓标志。
- 保留上下视各自的帧号和超时，不能用上视心跳保活下视。本工程实际主控现有观测超时为累计大于 400 ms；视觉发送端达到 300 ms 已发送过期状态，接入时保留各端原有处理口径。

视觉端已完成二次误差补偿，主控不要再次套用补偿模型。

## 4. 在放置流程中使用结果

主控先按本方颜色和携带物块类别选择安全区：绿色/黑色物资对应物资区，橙色伤员对应伤员区，再利用该区的位置和方位对准接近。

只在当前放置阶段、观测新鲜、目标类别及区域颜色匹配，且 `inside_valid=1 && object_inside=1` 时，采用“视觉已入仓”结果。边缘仍越界、判断无效或过期时不能沿用旧结果。该结果不是夹爪已释放或投放成功；释放、后退和退出后物体留存需要后续动作及核验。

RV3 为单向逐物体观测，不提供主控任务 ACK 或全局 `vision_ready`。当前线上也不传跨帧 `target_id`，主控业务结构中的序号只是本帧索引；第一阶段无干扰、单绿色物块可按类别和正确区域筛选，多同类物体时还需补充本次目标的关联，不能把任意同类已入仓物体当成本次任务完成。
