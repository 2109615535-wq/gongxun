# 问题003 搜索误抓安全区物块

记录日期为 2026-11-21。

## 实车现象

场地内几乎没有待搬运的物块时，小车有时会在搜索时发现安全区里已放置的物块，并驶向它进行抓取。首次更新后，实车反馈仍有误抓。

## 原因与修复

抓取入口原先根据物块类别、距离、方位和夹爪 ROI 选目标，缺少当前帧的安全区位置标记。已有的 `object_inside` 用于投放核验，需要同一物块连续三帧进入对应类别区域。

首次更新要求物块框完全包含在安全区框内。即使物块实际已在安全区，检测框边缘稍微外露也会被判为区外。按实车反馈，将抓取过滤改为比较同一相机当前帧的检测框。任一安全区与物块的 ROI 重叠面积达到物块 ROI 面积的 80% 时，`in_safety_zone` 当帧为 `1`，其余为 `0`。投放核验仍要求正确类别的安全区完整包含物块 ROI，且连续三帧成立。STM32 选目标和触发夹爪时跳过带标记的物块。下视在夹爪动作发出前看到区内物块占据夹爪 ROI 时，撤销已排队的抓取。

RV4 和任务 JSON 携带新标记。香橙派现用的 RV3 通过隐藏区内可抓取物块的抓取定位和夹爪 ROI 命中来兼容旧主控，同时回传类别和入仓结果。字段和切换方式见[视觉端 README](../../../perception/README.md)。

## 验证

回归覆盖四类物块、四类安全区、80% 和 79% 的阈值两侧、安全区丢失、多个安全区独立比较、RV3 抓取抑制和 RV4 标记。

首次部署的本地视觉回归 70 项通过，香橙派隔离回归 69 项通过。已通过 SSH 部署并重启服务，模型、上下视和 RV3 串口运行正常。

80% 阈值更新的本地视觉回归 71 项通过，香橙派隔离回归 70 项通过。回放首次更新后的板端观测，发现下视第 17452 帧中普通物块的 ROI 被安全区覆盖 99.88%，上视第 23797 帧中伤员物块的覆盖率为 91.01%。两帧的抓取过滤位均由旧版的 0 变为 1，回放生成的 RV3 报文屏蔽了对应物块的抓取信息，RV4 报文携带区内标记。

80% 阈值已通过 SSH 部署到香橙派。重启后模型、上下视及 RV3 串口均正常，整车试抓仍待现场复测。

主控已通过 RV4 串口与抓取过滤的定向验证，本机 STM32 固件已编译。整套主控测试仍存在原有的转向 PID 断言失败。实车主控等待烧录，之后可将香橙派切换至 RV4。实车验收分别测试只剩区内物块，以及同时有区内和区外物块的场景。
